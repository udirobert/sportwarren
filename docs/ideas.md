## AG Grid for stats surfaces

[AG Grid](https://www.ag-grid.com/javascript-data-grid/getting-started/) (free
Community edition) could make SportWarren's player career stats, match logs,
and squad leaderboards sortable/filterable/groupable — replacing the
spreadsheet metaphor with an even more powerful inline grid. The product's
core UX is tabular stats; AG Grid would bring Excel-level interaction
without custom table code.
